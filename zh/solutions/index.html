01

垂直行业 ERP

为那些经营现实无法塞进标准模块的行业，专门构建的企业资源管理系统。

一家汽车贸易公司和一家精装工程承包商，在运营上几乎没有共同之处，却常常被卖给同一套 ERP —— 只是界面上的标签换了换。结果是系统只能事后记录发生了什么，而真正的业务仍然跑在 Excel 和微信群里。

我们做的是相反的事：让系统的形状贴合业务的形状，这样干活的人才有理由去用它。

汽车贸易

  • VIN 级库存管理，区分在途、保税、展厅在库等状态
  • 按单车核算采购、运输、清关与到岸成本
  • 多币种采购与结算，区分已实现与未实现汇兑损益
  • 从车架号到发票的全链路追溯，支撑审计与质保索赔
  • 销售管线、预订、定金与交车交接管理

建筑装饰与精装工程

  • 对照工程量清单的项目预算，区分已承诺成本与实际成本
  • 变更单全流程跟踪：从申请、业主确认到计量开票
  • 分包合约包、进度款申请与质保金释放
  • 采购与领料绑定到具体项目，而非只挂在仓库上
  • 基于开票计划推导的现金流预测，而不是靠估

两个行业共通

  • 与真实审批层级一致的角色权限体系
  • 阿拉伯文、英文、中文界面，阿文为正确的从右至左排版
  • 符合阿联酋要求的增值税（VAT）处理
  • 可部署于贵司基础设施，或采用我们负责运维的托管方案
  • 提供完整 API 文档，系统永远不会成为数据孤岛
02

精选企业软件代理

一份精简而有主张的企业平台清单 —— 由我们完成选型、本地化、部署与支持。

采购企业软件很容易，让它真正在组织里扎下根却很难。问题通常不在产品本身，而在于租户设计、数据迁移、与现有系统的集成、管理员是否具备能力，以及出问题时能不能找到人。

我们只代理愿意被客户以此评判的平台，并承担上述这段落差，而不是交付一个 License Key 就算完事。

我们代理的平台

  • Lark（飞书国际版）—— 将即时消息、文档、审批、日历与组织通讯录整合为统一的数字化办公平台
  • Amap（高德）—— 面向物流与外勤团队的地理编码、路径规划、车队可视化与配送运营
  • 其他业务线工具，根据具体客户需求逐案筛选

我们负责的部分

  • 在任何人签字之前，先做需求匹配度评估
  • License 采购、租户开通与组织架构搭建
  • 从既有工具迁移，在可行范围内包含历史数据
  • 与贵司 ERP、财务系统或内部应用的集成
  • 管理员赋能与最终用户培训
  • 英文、阿拉伯文、中文一线技术支持

Lark 与 Amap 为其各自权利人的商标。每项合作的具体范围及商务性质，将在商务洽谈阶段以书面形式确认。

03 研发进行中

CorpOS —— AI 原生企业管理

我们的旗舰项目：一个由 AI Agent 在系统之间承载工作流转的运营层，而人只负责那些值得由人来做的决策。

过去三十年，企业软件一直在把「事后记录工作」这件事做得越来越好。CorpOS 试图解决更难的那个问题 —— 让工作本身流动起来。

它的前提是：一家公司本来就有自己的运营模型 —— 一个申请如何变成一次审批，一次审批如何变成一笔采购，一笔采购如何变成一次付款。今天这个模型存在于人的脑子里，以及系统与系统之间的缝隙中。CorpOS 把它显性化，为 Agent 提供执行所需的上下文，并在涉及判断、责任或客户关系的节点上把人放回来。

设计原则

  • 运营模型本身就是产品 —— 而不是在旧界面上加一个聊天窗口
  • 统一的公司知识层，让 Agent 与人依据同一套事实作答
  • 每一个自动执行的动作都可归因、可复核、可回滚
  • 需要判断的地方由人审批；确实不需要的地方交给自动化
  • 对公司现有系统保持开放接口

CorpOS 目前处于研发阶段。正式发布前，我们正与少量共创客户合作打磨产品 —— 如果这个问题正是您面临的，欢迎与我们联系。
